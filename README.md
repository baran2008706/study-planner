# study-planner

Why I built this:
I built this project because planning study time is an important part of my daily routine.
I wanted to turn a simple real-life problem into a python project and use programming to make study planning more organized.

Features:
Add Study Tasks - Set A Subject And Task Name - Set Study Duration - Set A Date - Set Task Priority - View Planned Tasks

How it works:
The program collects information about study tasks from the user and stores them during the programming session.
Users can view their planned tasks, check their study time, and mark completed tasks.
